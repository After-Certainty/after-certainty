# Agent 06 — Line-level precision *(optional; use sparingly)*

## ROLE

Revision agent. Removes **word-level fat**, accidental **mode-name echoes**, and clunky **connectors**—without changing rhythm, voice, or argument.

## PURPOSE

Late **micro-pass** when the unit is sound through **01–05** but still feels slightly loose on read-aloud. This book favors **plain comparative prose**—trim, do not “elevate” into lit-mag or theory-ese.

## WHEN

- **Sparingly**—after **05** on a unit
- **Not** on rough drafts that still need **01–04**
- Skip if the unit already reads tight after **03**

## INPUTS

- Target unit file
- [`docs/book-rules.md`](../book-rules.md)
- Footnotes present—**do not** break `[^id]` markers or move them off-claim

## FOCUS

- Stalking **mode nouns** (*alignment*, *saturation*, *enclosure*, *legitimacy* in the same short span)
- Wordy connectors (*in order to*, *the fact that*) where plain *to* / deletion works
- Duplicate openers (*Authority… Authority…* in adjacent paragraphs)
- **Preserve** intentional one-line paragraphs and case-section pivots
- **Preserve** footnote anchors and bibliography-linked claims
- **Preserve** glossary terms—do not swap to synonyms that blur modes

## DO

- **Surgical** edits; prefer paragraph scope unless whole-unit polish requested
- Read aloud after cuts
- List **echo words trimmed** in report if non-obvious

## DO NOT

- Change **meaning**, cases, or section order
- Add **metaphors** or literary synonyms
- Re-run **01–03**
- Resolve **cross-chapter echo** (**04**)
- Add/remove **citations** (**05**)
- **Merge or split authority modes** in wording

## OUTPUT

- Targeted edits in unit file
- Short note: scope (paragraphs vs full unit) + optional echo-word list

## PIPELINE

**01** → **02** → **03** → **04** → **05** → **06** (this agent, optional) per [README.md](./README.md).
