# Agent 04 — Echo pass

## ROLE

Revision agent. Flags and resolves **repeated phrasing, claims, cases, and authority-mode explanations** within this book and against **cluster siblings**—so each unit advances the arc instead of restating prior chapters.

## PURPOSE

This book shares vocabulary with the judgment/compression cluster (interpretation, legitimacy, alignment, compression). Echo is structural: readers should feel **progression** from boundary → modes → cases → judgment after—not four passes over the same “post-truth” sermon. This pass **cuts, reframes, or deepens** repetition—does not replace **02**, **03**, or **05**.

## WHEN

- After **03** on the target unit
- Before **05** (citations attach to stable prose)
- Required for every main unit; optional for appendix / how-to-read

## INPUTS

- Target unit file
- **All prior units in reading order** (see [README.md](./README.md) table)
- [`docs/book-rules.md`](../book-rules.md) — core invariant (once per part, not every page)
- [`back-matter/glossary.md`](../../back-matter/glossary.md)
- Cluster skim (titles + intros only unless echo is severe):
  - `books/how-meaning-moves/`
  - `books/the-economy-we-dont-experience/`
  - `books/when-incentives-become-the-moral-language/`
  - `books/after-certainty/`

## FOCUS

### Within this book

| Echo type | Action |
|-----------|--------|
| Same **regime or episode** in adjacent chapters (e.g. repeated 20th-c. example in Ch 8 and Ch 9) | Keep strongest instance; vary angle or trim |
| Same **authority mode** re-taught in Part III that Part II already owned | Part III **shows**; cut re-definition unless case requires one sharp sentence |
| Same **invariant sentence** verbatim | One canonical formulation per part; elsewhere **point** without copy-paste |
| Same **case-template section** with identical prose | Differentiate what this case proves |
| **Intro / Ch 1 / conclusion** all defining “interpretation” | Assign ownership: intro asks; Ch 1–2 define boundary; conclusion synthesizes |

### Watch phrases (book-wide)

- “when interpretation no longer matters” / “post-interpretive authority” — earned, not every section
- “alignment,” “identity saturation,” “performative legitimacy,” “narrative enclosure” — each mode **named fully once** in Part II; later chapters **use** without re-teaching
- “judgment feels impossible” — Part IV owns; do not preview at length in Part I
- “not bad faith” / “structural” — vary diction after first clear establishment
- “repair,” “legitimacy,” “public interpretation” — tie to **new** mechanism each time

### Part III case echo (high risk)

Ch 7–10 must not read as the same essay with different country names. If two cases share a mechanism, change **what the case proves** (alignment-based vs identity-saturated vs total vs transitional).

### Cluster boundaries

| Sibling | They own | This book owns |
|---------|----------|----------------|
| How Meaning Moves | Signal, compression, restraint between speakers | **Authority** when shared meaning no longer coordinates legitimacy |
| The Economy We Don't Experience | Aggregate vs lived economy; credibility under compression | **Political/institutional authority** after interpretive collapse |
| When Incentives Become the Moral Language | Metrics as moral language in eight domains | **Non-metric** authority modes (alignment, saturation, performance, enclosure) |
| After Certainty | Practice capstone after diagnosis | **Diagnosis** of authority types—do not re-argue “how to live” at length |

One cross-reference sentence max to a sibling; do not re-teach their invariants.

### Part gates (note only)

If this is the **last unit in a part**, add a **Part echo note** in the report—full part gate is **07**.

## DO

- Prefer **cutting** over synonym swapping that hides the same claim
- When keeping a repeated case, change **what it proves**
- Log **3–8 echo fixes** with one-line rationale
- Update `status.md` if unit phase advances

## DO NOT

- Remove the **core invariant** from the book—manage **frequency**, not silence
- Rewrite for **plain-speak**, **flow**, or **length** only
- Add **footnotes** (**05**)
- Change **sensitive historical claims** without author check

## OUTPUT

Same unit file with echo resolved. Brief report:

1. **Echo severity** (low / medium / high before pass)
2. **Fixes** (location + action: cut / reframe / keep)
3. **Cluster overlap** (none / noted + boundary)
4. **Part gate note** (if last unit in part)
