# Chapter edit pass — Boundary Conditions

Repeatable revision checklist for organizational-fiction voice and structure.

**Authority (resolve conflicts in this order):**

1. **[project-spec.md](./project-spec.md)** — premise, POV, cast, ending, anti-patterns  
2. **[voice-spec.md](./voice-spec.md)** — organizational-fiction engagement, dialogue, technical authenticity, recalibration rhythm  
3. **[synopsis.md](./synopsis.md)** — plot spine  
4. **[act-chapter-index.md](./act-chapter-index.md)** — chapter title, POV, beats  

**Drafting aid:** **[exemplar-chapter-01-drafting.md](./exemplar-chapter-01-drafting.md)** · **Agents:** **[agents/README.md](./agents/README.md)**

---

## Before you edit

- [ ] Confirm **single POV** (default Nate) per [act-chapter-index.md](./act-chapter-index.md)  
- [ ] Confirm chapter hits its **beat** on the synopsis spine  
- [ ] Act IV chapters: check **recalibration** tone in [recalibration.md](./recalibration.md)  

---

## Pass A — Facts, POV, chapter job

- [ ] Nate’s interior stays **restrained**—insight through observation, not manifesto  
- [ ] Technical claims match scene evidence (repro, doc, bridge argument)  
- [ ] No strawman Product or Security; both sides carry real constraints  

## Pass A1 — Reader-facing (no outliner bleed)

- [ ] No **Act/Part/chapter** labels, beat names, or “the novel” meta in manuscript prose  
- [ ] Foreshadowing uses **story time** (*later*, *months after*, *when they reached back*)—not editorial structure  
- [ ] Channel names and template fields may stay technical; planning-doc vocabulary may not  
- [ ] Optional agent: **[01-reader-facing-pass.md](./agents/01-reader-facing-pass.md)** after agent 00  

---

## Pass B — Flow and clarity (required)

- [ ] Run **[03-flow-clarity-editor.md](./agents/03-flow-clarity-editor.md)** after agent **02** (Pass C)  
- [ ] Nate POV anchored early; no ambiguous **he** after bridge stacks  
- [ ] Bridge/call scenes: every speaker **identifiable** on skim  
- [ ] Paragraph rhythm: merge orphan one-liners unless intentional staccato (roll call, landing beat)  
- [ ] Plain sense before abstraction; tame essay/consulting-deck narration  
- [ ] Cut outline bullets left in manuscript  
- [ ] Clock and location anchors when time jumps (airport, weeks later)  
- [ ] Act IV: quieter rhythm—don’t over-merge family/recalibration white space  

---

## Pass C — Organizational fiction voice (required)

- [ ] Run **[02-organizational-fiction-voice.md](./agents/02-organizational-fiction-voice.md)** (or equivalent checklist in [voice-spec.md](./voice-spec.md))  
- [ ] Scene opens with situation; chapter ends with **pull**  
- [ ] Dialogue **sayable**; meetings carry exposition through conflict  
- [ ] Jargon only when the room would use it—and grounded in stakes  
- [ ] Reader cares what happens next to Nate/Caleb—not only the technical fix  

## Pass C2 — Dialogue & voice (required when chapter has talk)

- [ ] Run **[04-dialogue-voice.md](./agents/04-dialogue-voice.md)** after agent **03**  
- [ ] Warren, Owen, Priya, Eli, Caleb **distinct**—not one corporate blob  
- [ ] Bridge/meeting: conflict and exposition through **quoted lines**, not narrator meeting recap  
- [ ] Cut throat-clearing and on-the-nose theme slogans in speech  
- [ ] Family/recalibration: quieter register; less bridge volley density  

---

## Pass D — Thematic signal (light touch)

- [ ] Run **[05-thematic-signal.md](./agents/05-thematic-signal.md)** after agent **04**  
- [ ] “Routing uncertainty to the reliable person” **shown** through routing behavior, not labeled every scene  
- [ ] Boundary themes (auth edge, org “not our system,” family load) **dramatized**—not title-as-thesis in narration  
- [ ] Family parallel **earned** in Acts II–III before Act IV boundaries  
- [ ] Act V: Nate helps **differently**—signal through action, not arc summary  

---

## Pass E — Pacing

- [ ] Act I–III: urgency without melodrama  
- [ ] Act IV: **quieter**—fewer simultaneous crises; contrast with earlier overload  
- [ ] Act V: return of pressure without undoing boundary growth  

---

## Pass F — Read-aloud (required before done)

- [ ] Run **[06-audio-readaloud.md](./agents/06-audio-readaloud.md)**  
- [ ] Bridge dialogue listenable in one pass; ambiguous **he/it** fixed for ear  
- [ ] No stacked em dashes; prefer commas or clean sentence splits  
- [ ] Intentional staccato preserved (*Recognition.*, roll call)  

## Pass G — Character consistency (optional)

- [ ] Run **[07-character-consistency.md](./agents/07-character-consistency.md)** when Warren/Owen/Priya/Caleb or Nate interior drifts  
- [ ] Nate: not savior, not cynic; Act IV–V boundary growth consistent  

## Pass H — Line-level precision (optional, sparing)

- [ ] Run **[08-line-level-precision.md](./agents/08-line-level-precision.md)** only when prose is otherwise sound—word echoes, micro-clunk
