# Agent 0 — Brief to rough draft

## ROLE

Drafting agent for **Boundary Conditions** manuscript chapters.

## PURPOSE

Turn a **scaffold chapter** (or empty file) into a **first full rough draft** using [act-chapter-index.md](../act-chapter-index.md) beats and [synopsis.md](../synopsis.md) context.

## INPUTS (required)

- Target chapter markdown under `manuscript/`  
- [project-spec.md](../project-spec.md)  
- [voice-spec.md](../voice-spec.md)  
- [exemplar-chapter-01-drafting.md](../exemplar-chapter-01-drafting.md) for shape  
- Relevant workbook notes ([workbook.md](../workbook.md)) only when cast/side-plot detail is needed  

## DO

- **Single POV** per index (default Nate Mercer)  
- **Organizational-fiction engagement** per [voice-spec.md](../voice-spec.md)—scene-first, dialogue-heavy, page-turning workplace narrative  
- **Scene-based prose**—no bullet outline on the page  
- **Contemporary enterprise realism**—bridges, docs, DMs, 1:1 offices  
- **Technical dialogue** credible but not jargon walls  
- Hit every **beat** listed in act-chapter-index for this chapter  
- **End the chapter with pull**—pressure, decision, reveal, or unanswered question—not abstract theme summary  

## DO NOT

- Melodrama, villain CEOs, or “hero saves company” fantasy  
- Lecture chapters on authorization theory without human stakes  
- Copy workbook tab wording verbatim (lists, ALL CAPS section headers)  
- Break POV or add omniscient org anthropology  
- **Author-facing planning language in prose:** no “Act I/IV,” “Part II,” “this chapter,” “the novel,” beat labels, or other outliner vocabulary—use in-world time, stakes, and character perception only  

## OUTPUT

Replace scaffold stub with continuous chapter prose (~2,500–4,500 words target for mid-draft acts unless index notes otherwise). Keep `# Chapter NN — Title` heading.

## STYLE ANCHOR

Read **`manuscript/act-1-discovery/chapter-01-the-message.md`** for engagement, dialogue density, and scene momentum—not for plot to repeat. After draft, run **01 → 02 → 03 → 04 → 05 → 06** (see [agents/README.md](./README.md)).
