# Boundary Conditions — agent specs

**One drafting agent** plus **revision agents** for organizational fiction. Copy a spec into a Cursor prompt with the chapter file and linked docs, or use as a human checklist.

**House rules (agents do not override):**  
[project-spec.md](../project-spec.md) → [voice-spec.md](../voice-spec.md) → [synopsis.md](../synopsis.md) / [act-chapter-index.md](../act-chapter-index.md)

**Checklists:** [chapter-edit-pass.md](../chapter-edit-pass.md) · **Gold chapter:** [exemplar-chapter-01-drafting.md](../exemplar-chapter-01-drafting.md)

All revision agents below are **Boundary Conditions–specific** (tailored from Velorum’s function, not Velorum voice).

---

## Suggested workflow (per chapter)

| Step | Agent | When |
|------|--------|------|
| **0** | [Brief-to-Rough-Draft](./00-brief-to-rough-draft.md) | Expand scaffold or empty chapter from index + synopsis |
| **1** | [Reader-facing](./01-reader-facing-pass.md) | Strip Act/Part/chapter meta from prose |
| **2** | [Organizational fiction voice](./02-organizational-fiction-voice.md) | Genre engagement—scene pull, business-novel pacing |
| **3** | [Flow & clarity](./03-flow-clarity-editor.md) | Referents, paragraph rhythm, bridge skim, time jumps |
| **4** | [Dialogue & voice](./04-dialogue-voice.md) | Speech-only—bridges, meetings, DMs, family |
| **5** | [Thematic signal](./05-thematic-signal.md) | Show themes through routing/behavior—no thesis labels |
| **6** | [Audio read-aloud](./06-audio-readaloud.md) | **Before chapter done**—listen/TTS tripwire |
| **7** | [Character consistency](./07-character-consistency.md) | Optional—when cast or Nate interior drifts |
| **8** | [Line-level precision](./08-line-level-precision.md) | Optional, sparing—word echoes and micro-clunk |
| **9** | [Technical realism](./09-technical-realism-agent.md) | Optional, tighten technical and organizational credibility |

**Recommended full pipeline:** **00 → 01 → 02 → 03 → 04 → 05 → 06** on dialogue-heavy chapters. Add **07** when voice feels off; **08** only late and local; **09** when institutional language feels over-authored.

Skip **0** when drafting by hand from the exemplar habits.

---

## Agent division of labor

| Layer | Agents |
|--------|--------|
| Meta / genre | **01**, **02** |
| Prose mechanics | **03** |
| Speech | **04** |
| Meaning (subtext) | **05** |
| Listenability | **06** |
| Cast truth | **07** |
| Word fat | **08** |

Do not skip **02** (genre) or **06** (read-aloud) when aiming for publishable chapters.
