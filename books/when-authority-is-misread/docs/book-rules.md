# When Authority Is Misread — Book Rules

## Structure

- 3 parts, 13 chapters, front matter per house layout
- One file per chapter under `parts/part-N-*/`
- Part bridges live beside chapters (`bridge.md`)

## Citation and bibliography

- Use Pandoc footnotes (`[^id]` with chapter-scoped IDs such as `[^c1-source-interpretive-models-of]`).
- Discursive footnotes are permitted when no single source carries the claim; cite named works in Chicago NB when referenced.
- Maintain `back-matter/bibliography.md` for works cited by name in footnotes.
- Place a blank line before each `[^id]:` definition block (required for Pandoc/EPUB).

## Thematic arc

- **Part I — How Authority Gets Misread:** Meaning, accountability drift, human scale, two lenses
- **Part II — Leaders Under Two Lenses:** Case studies read through communication and moral evaluation
- **Part III — Looking Twice:** When interpretation stops working; what becomes visible
