# Agent 04 — Echo pass

## ROLE

Revision agent. Flags and resolves **repeated phrasing, claims, cases, and mechanism explanations** within this book and against **cluster siblings**.

## PURPOSE

This book shares vocabulary with coordination and judgment cluster titles. Echo is structural: readers should feel **progression** from contribution → stabilizing → collapse → clearer sight—not four passes over the same “teamwork is hard” sermon.

## WHEN

- After **03** on the target unit
- Before **05**

## INPUTS

- Target unit file
- **All prior units in reading order** (see [README.md](./README.md) table)
- [`docs/book-rules.md`](../book-rules.md) — core invariant (once per part, not every page)
- [`back-matter/glossary.md`](../../back-matter/glossary.md)
- Cluster skim: coupling, interpretation, incentives, economy, how-meaning-moves, after-certainty

## FOCUS

### Within this book

| Echo type | Action |
|-----------|--------|
| Same **case** in adjacent chapters | Keep strongest instance; vary angle |
| Same **invariant sentence** verbatim | One canonical formulation per part; elsewhere **point** |
| **Core-reframe** re-taught in every chapter | Chapters **apply** visibility/asymmetry/control; do not re-list all three every close |
| **Ch 14 vs conclusion** | Ch 14 = affirmative inventory; conclusion = arc synthesis + pointer only |

### Cluster boundaries

| Sibling | They own | This book owns |
|---------|----------|----------------|
| Coupling | System architecture, responsibility graphs | **Human coordination** under diffuse ownership |
| Interpretation | Authority when public understanding collapses | **Contribution and trust** under partial visibility |
| Incentives | Metrics as moral language | **Stabilizing structures** that are not formula-substitution |
| Economy | Aggregate vs lived narrative | **Shared work** fragility, not CPI/forecast frame |
| How Meaning Moves | Signal/compression between speakers | **Group orientation** without full authorship |
| After Certainty | Practice capstone | **Structural diagnosis**—do not re-argue “how to live” at length |

## OUTPUT

Same unit file with echo resolved. Brief report: severity, fixes, cluster overlap, part gate note if last unit in part.
