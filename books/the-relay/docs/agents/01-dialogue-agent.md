- Heat lives in **dialogue**, not narration — see voice-spec per-character table.

- **Nadi / Dael / pilots:** blunt, can go heavy. **Lena:** moderate. **Jun / Sera / Toma:** rare.
- Vary curse **shape** — not the same word every third line.
