## Rewrite templates

### Keeper vs wall / security

Replace single wisdom line with **job vs audience**:

```
"I posted the inspection report."
"Nobody's reading inspection reports."
"Yeah, I noticed."
```

### Older woman / bystander

Replace essay observation with **deflection**:

```
"Either somebody knows and isn't talking, or nobody knows."
"Which do you think?"
"I think dinner's in an hour and my nephew's still going to complain."
```

### Pilot / Nadi vs cluster

Replace villain speech with **ledger**:

```
"You want separatists."
"I want a fee that matches the corridor."
"My ledger moved before your chart did."
"Then show the room."
```
