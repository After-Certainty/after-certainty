# The Relay — documentation index

**Start here:** [`00-design-handbook-overview.md`](./00-design-handbook-overview.md) — the entry point and constitution for the novel. It explains the seven guides, the governing laws, and how to use the handbook *lightly* while drafting.

This handbook is the canonical design memory for *The Relay*. The book's earlier canon has been superseded by these documents.
