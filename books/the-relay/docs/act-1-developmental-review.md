## New risk: evidence accumulation

Act I is rich—possibly too rich. Readers carry ~**3–5 active mysteries**; draft may ask for 10–12.

### Consolidate to three primary clue tracks

1. **Marks** — dot/stroke grammar; work on seams; Arin's photo
2. **Wrong border** — pamphlet; altered map; route clip that doesn't match
3. **Fees / wall** — percentages move freight; story tax; insurance; fees before bulletins

### Secondary (texture, not separate mysteries)

- Jun's brief (lens on wall, not new clue system)
- Keeper schedules / tolerance logs (**same track as marks**—don't file separately)
- Transit scans, route anomalies (procedure, not mystery)
- Sentiment filters (same track as personalized wall %)

### Rule going forward

**Stop adding clue systems. Make existing clues collide.**

Example collision (Ch. 4 target): wrong map on pamphlet + mark on seam + fee spike = three tracks, one decision.
