## 1. Expansion quality vs quantity

**Core question:** *Did the chapter get deeper—not just longer?*

### Good expansion

- Richer character interactions
- Stronger emotional beats
- Worldbuilding through action
- More conflict
- More difficult decisions
- Better scene transitions

### Bad expansion

- Repeating information
- Re-explaining themes
- Observations that don't change anything
- More examples of patterns already understood

## 3. Brittany test

**Skim risk:** over-explained themes · abstract language · literary observations that don't move plot

**Engage:** dialogue · sibling dynamics · concrete detail · mystery clues · visualizable worldbuilding

Run [14-brittany-agent](./agents/14-brittany-agent.md) after expansion; flag Voice 3 with [16-contemporary-readability](./agents/16-contemporary-readability-agent.md). Run [18-future-texture-agent](./agents/18-future-texture-agent.md) for non-Velorum visual/social detail.

## 4. Voice drift — two dangers

| Version A (systems) | Version B (literary) |
|---------------------|----------------------|
| Sociology, epistemology | Poetic observations |
| Explanation | Atmospheric reflection |
| Jun vocabulary in Lena narration | Pull-quote sentences |

**First-read clarity:** Stacked proper nouns + unexplained transport terms in one sentence → split or simplify. Compressed metaphors (*He sent weather*) → concrete (*storms and mirror work*).

**Target middle:** Clear · Concrete · Human · Occasionally beautiful.

---

## 5. Novel length (90–100k)

Added material should support length through:

- Stronger character relationships
- More difficult travel
- More discoveries
- More conflicting evidence
- More consequences

**Not through:** theme discussion · explanation · description for its own sake
