Each unit advances the arc instead of restating prior chapters. Does not replace **02**, **03**, or **05**.

## WHEN

- After **03** on the target unit
- Before **05**
- Required for every main unit

## INPUTS

- Target unit file
- **All prior units in reading order** ([README.md](./README.md))

## FOCUS

### Within this book

| Echo type | Action |
|-----------|--------|
| Same **example** (drug shortage, reorg manager, hospital committee) | Keep strongest; vary or trim others |
| Same **invariant sentence** verbatim | One canonical formulation per part; elsewhere **point** |
| **Opening/closing** repeats prior chapter | Add nuance or shorten |

### Watch phrases

- “patterns as warnings not verdicts” — earned, not every section
- “probabilistic seriousness” / “not moral relativism” — tie to **new** mechanism each time
- “false prophecy” — do not become tic
- “not bad faith” / “structural” — vary after first establishment

### Cluster boundaries

- Do **not** re-argue *After Certainty* capstone arc or economy two-clocks—one sentence max
- This book owns **disciplined uncertainty**, **warnings vs verdicts**, **institutional drift**, **leadership without prophecy**

### Part gates (note only)
