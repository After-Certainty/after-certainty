## Target scene-to-essay ratio

| Metric | Ch 6 (benchmark) | Avoid (Ch 5 pre-pass) |
|--------|------------------|------------------------|
| Scene time | ~60% | ~20% |
| Exposition | ~40% | ~80% |
| Max consecutive expository paragraphs without scene return | 3–4 | 7+ |
| Core Principle at end | Yes, adds one distinction | N/A |

**Rule:** After every 2–3 explanatory paragraphs, return to a named character or concrete object (whiteboard, shared doc, phone, coffee pot).

---

## Interleaving structure (Ch 6 movements)

| # | Movement | Scene anchor |
|---|----------|--------------|
| 1 | Situation opens; meaning already moving | Philip, Nora, whiteboard |
| 2 | One conceptual widening tied to scene | Authority + tentativeness |
| 3 | Return to character or object | Hallway; document gap |
| 4 | Second scene with dialogue | Nora check-in exchange |
| 5 | Optional institutional widening | Minutes, legitimacy |
| 6 | Observable consequence | Anna withholds question |
| 7 | Core Principle — one new distinction only | End |

Do not leave Philip/Nora/Anna (or Mara/Leo) for 7+ expository paragraphs.

---

## Core Principle discipline

- Appears **once**, at chapter end only.
- Must add **one distinction** the scene did not already show — not a summary.
- Cut "Seeing this clearly does not X. It explains Y." when the scene already landed.
- Avoid restating the last scene beat-for-beat.

---

## Curiosity before explanation

1. Hold one beat of unresolved curiosity before naming Signal, Compression, or Restraint.
2. No bold mini-headings that function as thesis labels mid-chapter.
3. No framework announcements ("That gap is where this chapter lives").
4. One historical/institutional widening per chapter max; return to scene before the next.
