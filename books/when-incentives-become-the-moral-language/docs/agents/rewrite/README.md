## Rewrite sequence (production order)

Not the same as reading order. See plan §16.

1. Introduction → Ch 1 → Ch 9 (provisional) → Ch 10 → Interlude
2. Ch 2–8
3. Ch 9 revision → Ch 11 → Ch 12 + Epilogue
4. Transitions → citations → voice

---

## Forbidden in reader-facing prose

- `### The Original Moral Aim` and labeled scaffold headings
- "Three mechanisms carry/drove/shape the shift" (except once in Ch 9)
- "None of these tools claims…"
- "Central question:" opener
- `### Moral Residue` heading before Part IV
- Chapter-ending previews by number/name
- Named patients/employees or fake quotations as reported fact
