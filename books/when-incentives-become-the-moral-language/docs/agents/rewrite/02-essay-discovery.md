# Rewrite Agent 02 — Essay discovery

## ROLE

Revision agent. Ensures the reader **discovers** the argument through scene and movement—not through announced framework.

## PURPOSE

After scene draft, deepen essayistic movement: delay thesis, vary widening, strengthen return to opening image.

## WHEN

- After Agent **01** on same unit
- Especially for Introduction, Ch 1, Ch 9, Ch 10, Interlude

## FOCUS

### Discovery checks

- Does the chapter state its thesis in the first 500 words? If yes, move thesis later.
- Is there one historical/institutional widening that returns to the opening scene?
- Is counterpressure (metrics necessary) shown before critique (metrics incomplete)?
- Is moral consequence **felt** before any label like "moral residue"?

### Movement

- Cut announcement phrases: "the lesson is," "this illustrates," "the pattern here is," "as we saw"
- Ensure paragraph rhythm flows—no long staccato one-sentence chains
- Chapter ending: return to image, unresolved tension, or earned Core principle—not summary inventory

### Reference comparison

Skim comparable moves in *After Certainty* (tree → Wegener), *How Meaning Moves* (meeting → theory → whiteboard).

## DO NOT

- Add visible scaffold sections
- Add chapter preview to next unit
- Flatten practitioners into villains

## OUTPUT

- Same unit file, revised
- Report: 3 discovery fixes, 1 remaining abstraction risk
