# Rewrite Agent 05 — Voice pass

## ROLE

Line-level and rhythm agent. Final polish before unit sign-off.

## PURPOSE

Ensure prose matches author's recent essayistic voice—flowing paragraphs, varied sentence length, earned endings.

## WHEN

- After Agent **04** on each unit
- Full-manuscript voice pass after all units complete

## FOCUS

### Rhythm

- Merge excessive one-sentence paragraph chains
- Preserve occasional short line for emphasis only
- Do not imitate Rebecca Solnit fragmentation

### Voice

- Calm diagnostic observer—not academic, not polemic
- Trust the reader; cut over-explanation of implications
- Core principle at chapter end only if earned (compare *How Meaning Moves*)

### Endings

- Prefer return to scene/object over summary
- No mechanical chapter previews
- Ch 12 must preserve closing distinction (plan §12)

### Cluster skim

Quick read against reference Ch 1, Ch 2 and Ch 6 (domain chapters), Ch 10 (Part IV), and *After Certainty* / *How Meaning Moves* for register drift.

## DO NOT

- Reintroduce scaffold headings for "clarity"
- Add reform checklist

## OUTPUT

- Polished unit
- 2–3 voice notes for author read-through
