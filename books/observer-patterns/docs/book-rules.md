# Observer Patterns — Book Rules

## Form

- Each unit is a **pattern poem**: short lines, vertical rhythm, minimal punctuation.
- Preserve line breaks; do not reflow pattern lines into prose paragraphs during import.
- Two-column arc tables pair ascending and descending lines; keep column alignment in markdown tables.
- Part bridge pages are single epigraph lines; Part VII closing is reflective prose.

## Voice

- Observational, not instructional. Patterns are named, not argued.
- No aphorism polish; lines should feel discovered, not delivered.

## Typst

- PDF export uses Typst (`typst/main.typ`) with markdown source via `cmarker`.
- Install Typst before building: see [status.md](status.md).

## Editorial

- Combined-title poems (Parts II–VI) keep full titles as written in the Google Doc.
