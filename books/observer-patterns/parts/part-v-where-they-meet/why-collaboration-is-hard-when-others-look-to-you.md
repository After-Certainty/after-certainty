## Why Collaboration Is Hard When Others Look To You

Difference is present.

Attention finds a focus.

Context varies.

Examples accumulate.

Priorities converge.

Leadership coalesces.

Coordination forms.

| | |
| --- | --- |
| Understanding aligns. | Understanding diverges. |
| Feedback drives change. | Disagreement is suppressed. |
| Leaders feel the consequences. | Exceptions are forever. |
| Feedback flows. | Feedback stops. |
| Assumptions are tested. | Learning collapses. |
| Dissent is welcomed. | Priorities conflict. |
| Ownership holds. | Ownership diffuses. |
| Work progresses. | Work stalls. |
| Trust grows. | Trust erodes. |
| Collaboration holds. | Coordination breaks. |
|  | Collaboration fails. |

Leadership reproduces itself.
