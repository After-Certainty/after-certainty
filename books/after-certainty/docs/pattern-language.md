# After Certainty — Pattern Language (Light Surfacing)

**Locked for this book (2026).** Do not add named patterns without a strong manuscript reason. Portfolio books may reference these ten; wording stays stable.

## Locked set

**Drift:** Correctness Hardens Into Identity · Explanation Replaces Response · Admiration Becomes Insulation · Blame Compresses Complexity

**Counter-disciplines:** Revisability Preserves Judgment · Responsibility Persists Beyond Control · Scrutiny Preserves Trust · Attention Restores Contact

**Conditions of drift:** Finality Compensates for Uncertainty · Speech Escalates Faster Than Meaning

Pairings are tensioned and responsive (see appendix), not mechanical opposites.

---

Post-certainty **epistemic-moral patterns**: virtues that distort under scale—not bad behaviors, but seriousness overextended.

Distinct from WOLTY-style structural patterns (organizational vitality, recursive institutional dynamics). This book names how stabilizers fail when coordination exceeds human scale.

## Naming target

3–5 words with **motion** (hardens into, replaces, becomes, escalates, preserves, restores)—recognizable before theoretical. WOLTY-like rhythm: *Attention Finds a Focus*, *Examples Accumulate*. Not ultra-compressed slogans.

## Rules (non-negotiable)

1. **Prose first, name second** — The pattern must feel discovered, not announced.
2. **Bold inline compression only** — One line: `**Explanation Replaces Response.**`
3. **Sparse** — At most 1–2 bold surfacings per chapter; only patterns in the core set below. (Chapters may weave additional core patterns when earned; avoid stacked declarations.)
4. **Never** — Pattern callout boxes, formal “Pattern:” sections, numbered taxonomies (“the ten patterns”), diagrams in chapter prose, or re-defining a pattern every time it appears. (The introduction and appendix may include the orientation diagram: `docs/diagrams/pattern-map.svg`.)
5. **Not in vignettes** — No bold pattern names inside `Vignette Block` text.
6. **Scarcity** — The appendix holds the full field guide; chapters surface a subset. Do not add new named patterns without revisiting the core ten.

## Format

After a paragraph (or short sequence) that earns the insight:

```markdown
Over time, explanation can begin replacing response itself.

**Explanation Replaces Response.**
```

Title case. Prefer noun-phrase compressions with directional verbs.
