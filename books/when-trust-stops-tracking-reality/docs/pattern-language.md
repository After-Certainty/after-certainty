## The Trust Cycle

Beliefs → Actions → Outcomes → Trust → Participation → Beliefs

Healthy trust remains connected to feedback. Participation continues testing trust against outcomes.

When participation stops testing and starts confirming, the same cycle can drift: trust becomes identity, identity shapes interpretation, and interpretation encourages preservation. The cycle continues, but learning weakens. Healthy trust recovers when participation, outcomes, and feedback become connected again.

## Rules

1. **Prose first, name second** — The pattern must feel discovered, not announced.
2. **One pattern per chapter** — Named in Core Principle; do not re-catalogue all nine in every chapter.
3. **Chapter scaffold** — Title + central question; content-specific subheads; **Core Principle** section at close. No formulaic cross-chapter headers.
4. **Cross-book patterns** — If a pattern exists in the semantic graph, align prose with canonical definition when drafting.
