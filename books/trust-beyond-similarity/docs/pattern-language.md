## Rules

1. **Prose first, name second** — The pattern must feel discovered, not announced.
2. **One pattern per chapter** — Named in Pattern Statement; do not re-catalogue all nine in every chapter.
3. **Six-beat chapter structure** — Anchor Story → Why It Forms → Where It Drifts → What Remains → Pattern Statement → Closing Return.
4. **Cross-book patterns** — If a pattern exists in the semantic graph (e.g. Scrutiny Preserves Trust), align prose with canonical definition when drafting.
