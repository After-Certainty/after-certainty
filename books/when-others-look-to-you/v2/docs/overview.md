# When Others Look to You — v2 docs overview

This folder holds **editorial and production docs** for the **v2 manuscript**
(`books/when-others-look-to-you/v2/`): one chapter per **named pattern**, woven through
the four movements **Forming → Renewing → Eroding → Repeating** (part titles in
the manuscript; Appendix B’s four labels are **forming / adjusting / eroding /
circulating**).

The v1 manuscript lives in `books/when-others-look-to-you/v1/` with a different spine
(thematic parts, renewal/erosion center, circulation merged into Part II). Many
house rules are **edition-agnostic**; those remain authoritative in **v1
`docs/`** unless this folder says otherwise.
