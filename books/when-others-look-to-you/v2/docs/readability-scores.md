# Readability scores (v2)

> **Not generated yet.** The v1 script is `../v1/scripts/readability_scores.py`
> with a **hard-coded v1 manuscript file order**. To generate this file for v2:

1. Duplicate the script as `v2/scripts/readability_scores.py` **or** add a
   `--book-root` / `--ordered` option and point at `books/when-others-look-to-you/v2`.
2. List v2 files in reading order (`index.md` links are a good source of truth).
3. Write output to `books/when-others-look-to-you/v2/docs/readability-scores.md`.

Method and metric definitions match v1’s `readability-scores.md` preamble.
