# Fact-Check Checklist

Use before marking a drafted unit’s citation pass complete. Planning-only units remain unchecked.

## Before drafting

- [ ] Planning brief reviewed
- [ ] Source log started for central claims
- [ ] High-risk dossier complete if Chapter 4 or 7
- [ ] No reliance on cultural memory for central factual claims

## Claim hygiene

- [ ] Every memorable anecdote has a source row
- [ ] Dates are explicit and match sources
- [ ] Quotes are exact or clearly marked as paraphrase
- [ ] No “everyone believed / the public decided / people saw” without scoped evidence
- [ ] Contemporaneous interpretation is labeled separately from retrospective interpretation
- [ ] Author analysis is not presented as documented fact

## Case-specific

- [ ] Primary case chronology is consistent across the chapter
- [ ] Supporting cases are not overloaded with unverified detail
- [ ] Necessary complication / counterexample is research-aware, not hand-waved

## Publication hygiene (later)

- [ ] Footnote IDs are stable and chapter-scoped
- [ ] Bibliography / source list entries match footnote targets
- [ ] Living subjects’ later statements are dated and not collapsed into original-event narration
