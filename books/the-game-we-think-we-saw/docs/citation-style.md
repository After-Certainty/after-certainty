# Citation Style — *The Game We Think We Saw*

Chicago-notes style for manuscript footnotes (Pandoc `[^label]`).

## Rules

1. **Full citation on first appearance** of a source in the book (or, for clarity, on first appearance in a chapter when a short form would be ambiguous).
2. **Shortened citation thereafter:** Author or organization, “Short Title.”
3. **No exact repeated notes.** Do not re-cite the same source with a second footnote marker when the later claim is already supported by an earlier note. Prefer one note over duplicate numbered footnotes (Pandoc numbers each marker separately even when labels match).
4. **Organizations as authors** when no personal byline is primary: Associated Press, NFL.com, International Olympic Committee, Centers for Disease Control and Prevention, Major League Baseball, etc.
5. **Consistent dates:** Month Day, Year (e.g., October 15, 2017).
6. **Citation first, brief gloss second** when a factual gloss is needed. Avoid long narrative annotations that retell the body.

## Forms

Full article:

> Author, “Title,” *Publication*, Month Day, Year, URL.

Full institutional / web:

> Organization, “Title,” Month Day, Year, URL.

Short:

> Author, “Short Title.”

Book:

> Author, *Title* (Place: Publisher, Year).

Case:

> *Case Name*, volume U.S. page (year), URL.

## Function-separated notes

When chronology matters, split notes by function rather than loading later outcomes into earlier citations (e.g., grievance filing vs. settlement).
