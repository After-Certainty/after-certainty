## Why Diversity Matters When Others Look To You

Difference is encountered.

Attention finds a focus.

Variation accumulates.

Examples accumulate.

Perspective expands.

Leadership coalesces.

| | |
| --- | --- |
| Dissent is welcomed. | Disagreement is suppressed. |
| Assumptions are tested. | Understanding fragments. |
| Feedback drives change. | Exceptions are forever. |
| Understanding deepens. | Division forms. |
| Leaders feel the consequences. | Learning stalls. |
| Common ground forms. | Learning collapses. |
| Resilience grows. | Exclusion is reinforced. |
| Inclusion is practiced. | Fragility increases. |
| Learning accelerates. |  |

Leadership reproduces itself.

What persists reflects what was included.
