## Why Diversity Matters When Trust Builds And Others Look To You

Difference is encountered.

Trust is offered.

Attention finds a focus.

Variation accumulates.

Small risks compound.

Examples accumulate.

Assumptions are tested.

Vulnerability is tested.

Perspective expands.

Leadership coalesces.

| --- | --- |
| Reliability forms. | Understanding fragments. |
| Understanding deepens. | Trust shatters. |
| Trust holds. | Disagreement is suppressed. |
| Common ground forms. | Division forms. |
| Dissent is welcomed. | Exposure retreats. |
| Repair begins. | Learning stalls. |
| Learning accelerates. | Exceptions are forever. |
| Feedback drives change. | Fragility increases. |
| Trust demands openness. | Trust withdraws. |
| Resilience grows. | Learning collapses. |
| Leaders feel the consequences. | Exclusion is reinforced. |
| Inclusion is practiced. |  |
| Trust is built. |  |

Leadership reproduces itself.

What persists reflects what was included.
