## How to update

### Word counts

```bash
wc -w upcoming/velorum/manuscript/act-*/chapter-*.md
```

Or one chapter:

```bash
wc -w upcoming/velorum/manuscript/act-3-the-break/chapter-18-collapse-in-public.md
```

### After a chapter pass

1. Run `wc -w` on the chapter file  
2. Update **Current** and **Gap** in the chapter row  
3. Set **Status** (`in progress` → `partial` / `done`)  
4. Add a short **Notes** cue (branch, agent, what expanded)  
5. Recalculate act total and book summary tables  
6. Update *Last updated* line at top  

### Marking `done`

- **Current** within **~±10%** of chapter **Target**, or  
- **Beat-justified** under target (e.g. ch. 23 / 30 sparse hinges) with act total still in **Range**
