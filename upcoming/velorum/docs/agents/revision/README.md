# Velorum - Category Revision Agents

These agents are an optional **category pipeline** for later-stage chapter revisions.
They are designed to deepen emotional/relational texture without sacrificing Velorum's
clarity, tactical readability, and grounded voice.

Current standard for all acts: apply **Direct camera style pass** from
`../../voice-spec.md` (American conversational dialogue, camera-observable narration,
cut condensed literary metaphors, action-first meaning, fewer thesis lines, profanity
preserved in dialogue) via **`initial-drafting/13-direct-camera-style-pass.md`**
after **`03-flow-clarity-editor.md`**. Use this revision folder only for targeted
texture—not as a substitute for agent **13**.

Use these after core chapter drafting/revision is stable.

## Entry Criteria (required)

Before running this folder, chapter should already have completed core initial chain:

- `initial-drafting/03-flow-clarity-editor.md`
- `initial-drafting/04-embodiment-sensory-grounding.md`
- `initial-drafting/05-dialogue-voice.md`
- `initial-drafting/06-thematic-signal.md`
- `initial-drafting/07-pacing-structural-tension.md`
- `initial-drafting/09-audio-readaloud.md`

Treat this folder as targeted branches, not a second default full-chain.

## Recommended Order

1. Core chain complete (see Entry Criteria above)
2. `01-embodiment-agent.md`
3. `02-bond-tension-agent.md`
4. `06-dialogue-subtext-agent.md`
5. `03-myth-formation-agent.md`
6. `07-softness-longing-agent.md`
7. `08-world-pressure-agent.md` (as needed by chapter)
8. `04-operational-intimacy-agent.md` (as needed; protect competence texture)
9. `09-contemporary-flow-agent.md` (**rescue only** when chapter still reads dense after core chain)
10. `10-contemporary-fantasy-accessibility-agent.md` (**rescue only** when accessibility still fails after `09`)
11. `05-scene-compression-agent.md` **last**

Compression is intentionally last so earlier passes can add needed implication/texture
without immediately regrowing explanatory prose.

After compression, rerun `initial-drafting/09-audio-readaloud.md` (and optional `12-read-aloud-cadence-clarity-editor.md` if needed).
