## Post-expansion workflow *(book-scale)*

After each act meets expansion word targets:

1. **[post-expansion/01-narrative-density](../post-expansion/01-narrative-density-agent.md)** — **first**: remove redundant proof; merge beats; flag reinvestment sites.  
2. **[post-expansion/02-reality](../post-expansion/02-reality-agent.md)** — **second**: human/institutional friction; strip gobbledygook; scene anchors.  
3. **[post-expansion/03-consequence](../post-expansion/03-consequence-agent.md)** — **third**: reinvest cuts with escalation; preserve novel length.  
4. **[post-expansion/04-character-voice](../post-expansion/04-character-voice-agent.md)** — **fourth**: distinct mouths; stop author-voice convergence.  
5. **[post-expansion/05-world-pressure](../post-expansion/05-world-pressure-agent.md)** — **fifth**: operational strain; living system not symbolic backdrop.  
6. Core chain touch-up (**04** camera, **03** flow) on flagged scenes only.  
7. **07-scene-compression** last — do not compress before the full post-expansion stack.

Expansion **invents** texture under word-count pressure; **01** removes over-proof; **02** replaces placeholder texture; **03** reinvests as chain reactions; **04** re-mouths dialogue; **05** makes strain operational. **~50%** revision effort on **01**, **~20%** on **04**.

## Recommended order (when multiple apply)

1. Core chain complete *(or skip if running post-expansion stack on freshly expanded act)*  
2. **Post-expansion:** **[01](../post-expansion/01-narrative-density-agent.md) → [02](../post-expansion/02-reality-agent.md) → [03](../post-expansion/03-consequence-agent.md) → [04](../post-expansion/04-character-voice-agent.md) → [05](../post-expansion/05-world-pressure-agent.md)**  
3. **01** bond-tension (bond chapters)  
4. **02** dialogue-subtext  
5. **03** / **04** / **05** as needed — **05** adds operational pressure; **02** audits believability (**do not** use **05** to re-add invented labels **02** removed)  
6. **06** operational-intimacy (action/tactical chapters)  
7. **07** scene-compression **last**  
8. Re-run **09-audio-readaloud** (optional **13-read-aloud-cadence**)
