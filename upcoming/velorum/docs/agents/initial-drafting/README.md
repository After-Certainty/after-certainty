# Velorum — agent specs

**One drafting agent** plus **twelve revision agents** (numbered **01–12**). Copy a spec into a Cursor agent prompt (with the chapter file and linked docs) or use as a human checklist.

**Category subfolder for later revisions:**  
For a specialized narrative-refinement set (embodiment, bond tension, myth formation, operational intimacy, dialogue subtext, softness/longing, world pressure, and compression-last), see **[revision/README.md](../revision/README.md)**.

**Suggested order after a rough draft:** optional **[11](./01-chapter-expansion-depth-pass.md)** (**chapter mass / depth**) → optional **[01](./02-cinematic-scene-pass.md)** (**vivid scene / “camera”** ground) → **[02](./03-flow-clarity-editor.md)** through **[06](./07-pacing-structural-tension.md)** as needed → optional **[12](./08-narrative-revision-agent.md)** (**chapter-arc coherence / payoff alignment**) → **[07](./09-audio-readaloud.md)** → optional **[08](./10-character-consistency.md)** / **[09](./11-line-level-precision.md)** → optional **[10](./12-read-aloud-cadence-clarity-editor.md)**. **Not every revision pass every time**—run the layers the draft actually needs; **[12](./08-narrative-revision-agent.md)** is for chapter-level narrative unification after core scene/dialogue/theme work, and **[10](./12-read-aloud-cadence-clarity-editor.md)** is an **optional final polish** after **[07](./09-audio-readaloud.md)** when audiobook-style cadence is the bar. Use **[11](./01-chapter-expansion-depth-pass.md)** only when a chapter is complete but reads materially thinner than the Act I baseline. For **one chained prompt** that runs **Flow → Pacing** then **Read-Aloud Cadence** as ordered stages (shared rules + change budget), see **[final-polish-six-stage-pipeline](./final-polish-six-stage-pipeline.md)** *(prepend optional **[01](./02-cinematic-scene-pass.md)** when you want the pipeline to start from richer scene geography)*.

**On every numbered pass, carry [POV](#pov-close-third):** confirm the chapter host on **[act-chapter-index.md](../../act-chapter-index.md)** and use the **[checkpoints table](#pov-checkpoints-by-agent)** so camera, referents, audio, and interior voice stay aligned with that spec—not only when you remember to open the POV section.

**On every pass, also carry [Concrete description](#concrete-description-default):** Velorum’s default is **plain, camera-observable, sayable** prose—**[voice-spec.md](../../voice-spec.md)** *plain sense* / *camera-observable narration*—not **literary decoration**. Use the **[concrete checkpoints table](#concrete-checkpoints-by-agent)** with the numbered spec so agents don’t stack metaphors or poetic figuration by habit.

**House rules (agents do not override):**  
[project-spec.md](../../project-spec.md) → [voice-spec.md](../../voice-spec.md) → [synopsis.md](../../synopsis.md) / [act-chapter-index.md](../../act-chapter-index.md)

## POV (close third)

Each prose chapter has an assigned viewpoint on **[act-chapter-index.md](../../act-chapter-index.md)**—typically **Riven** or **Cael** (later **Lyra** where noted). During revision, **keep that lens consistent**: narration and free indirect thought belong to the POV character; avoid slips into another head’s interior unless the draft already uses a deliberate device (e.g. bond).

**Anchor POV early** after the chapter heading—usually within the **first paragraph**—with the POV character’s **name, body, or perception**. **Exception:** **Chapter 1** may open **place-first / world-building** before locking to Riven.

When **two male leads** share a scene, prefer **named beats** or **role cues** over stacked **he** before listeners confuse who acted. **[02](./03-flow-clarity-editor.md)** and **[07](./09-audio-readaloud.md)** are the primary passes for referent clarity; **[08](./10-character-consistency.md)** catches interior that sounds like the wrong lead; **[10](./12-read-aloud-cadence-clarity-editor.md)** must not “fix” cadence by head-hopping.

### POV checkpoints by agent

Carry these **with** the numbered spec when you paste or follow an agent—same prompt session, same chapter.

| # | Agent | POV responsibility |
|---|--------|-------------------|
| **0** | [Brief-to-Rough-Draft](./00-brief-to-rough-draft.md) | Draft **only** the index POV; anchor name/body/perception early unless a deliberate place-first open matches the brief (see § POV above). |
| **1** | [Cinematic Scene Pass](./02-cinematic-scene-pass.md) | Geography and light as **that POV’s** line of sight—not a neutral drone unless intentional. |
| **2** | [Flow & Clarity](./03-flow-clarity-editor.md) | Add early anchor if missing; clarify **he/it/they**; merging paragraphs must not blur **who thought/said/felt** or drift heads. |
| **3** | [Embodiment](./04-embodiment-sensory-grounding.md) | Sensation lands on the **POV** body (bond/exchange beats excepted). |
| **4** | [Dialogue & Voice](./05-dialogue-voice.md) | Tags/beats keep speakers clear **without** parking interior in the wrong head. |
| **5** | [Thematic Signal](./06-thematic-signal.md) | Motifs and pressure through **POV-perceived** objects/action—no narrator thesis; no omniscient widen. |
| **6** | [Pacing & Tension](./07-pacing-structural-tension.md) | Hinges land in **POV time**; trim drag without stepping outside the chapter lens. |
| **7** | [Audio Read-Aloud](./09-audio-readaloud.md) | **Listener *he*** after quick Riven/Cael exchange; never “fix” audio by hopping omniscient. |
| **8** | [Character Consistency](./10-character-consistency.md) | Flag stretches where **voice/interior** reads like the **non-POV** lead without a justified bond beat. |
| **9** | [Line-Level Precision](./11-line-level-precision.md) | Micro-tighten **without** shifting POV to resolve an echo. |
| **10** | [Read-Aloud Cadence](./12-read-aloud-cadence-clarity-editor.md) | Cadence and bridges **inside** the chapter host—no clarity-through-head-hop. |
| **11** | [Chapter Expansion & Depth](./01-chapter-expansion-depth-pass.md) | Expand under-length chapters while preserving canon beats, POV, and concrete scene pressure. |
| **12** | [Narrative Revision](./08-narrative-revision-agent.md) | Strengthen chapter-arc causality, pressure continuity, and payoff without breaking POV or canon order. |

## Concrete description (default)

**Vivid because concrete**, not because ornate: readers should be able to **point** to what’s on the page—light, material, motion, sound—or hear it clearly when read aloud. Prefer **named things** (*mast lantern, shale grit, hinge*) and **plain verbs** over stacked similes, **unearned personification** (*metal asking to be noticed*, *silence like a third person*), or figurative chains that **sound pretty but don’t picture**. One **accurate** sensory or spatial detail usually beats two poetic parallels.

**Exceptions:** dialogue may stay sharp or crude without being “camera”; canon words (**Heartbridge**, **Ashring**) stay; **deliberate** character-colored metaphor is fine when it’s clearly **their** thought—not narrator wallpaper.

### Concrete checkpoints by agent

| # | Agent | Concrete / plain diction |
|---|--------|---------------------------|
| **0** | [Brief-to-Rough-Draft](./00-brief-to-rough-draft.md) | **Observable nouns** and work-language defaults; don’t draft toward “literary” ornament—rough plain beats rough purple. |
| **1** | [Cinematic Scene Pass](./02-cinematic-scene-pass.md) | Add **seeable** geography and **named** light only; no **metaphor stacks** for “mood.” |
| **2** | [Flow & Clarity](./03-flow-clarity-editor.md) | **Tame bookish** lines; **swap** figurative or thesis-shaped phrasing for **map-plain** alternatives when the same information fits (**agents README → Concrete**). |
| **3** | [Embodiment](./04-embodiment-sensory-grounding.md) | **Flesh, material, contact**—not a second layer of poetic imagery on the same beat. |
| **4** | [Dialogue & Voice](./05-dialogue-voice.md) | **Mouth language** (mud, rent, rope); no **poetic stage directions** in adjacent narration when a **body fact** will do. |
| **5** | [Thematic Signal](./06-thematic-signal.md) | **Objects, labor, and recurrence** carry theme—**not** abstract theme-labels in narration. |
| **6** | [Pacing & Tension](./07-pacing-structural-tension.md) | Cut **ornament** that doesn’t add **physical or causal** clarity at a hinge. |
| **7** | [Audio Read-Aloud](./09-audio-readaloud.md) | If a simile **doesn’t image** on first listen, **rephrase** to concrete sound/sight/motion. |
| **8** | [Character Consistency](./10-character-consistency.md) | Voice drift sometimes shows up as **fancy narrator** diction—bring back **character-plain**. |
| **9** | [Line-Level Precision](./11-line-level-precision.md) | Prefer **shorter plain words** over **lyrical** synonyms when rhythm stays intact. |
| **10** | [Read-Aloud Cadence](./12-read-aloud-cadence-clarity-editor.md) | Smooth cadence **without** prettifying diction or adding **new** figurative curls. |
| **11** | [Chapter Expansion & Depth](./01-chapter-expansion-depth-pass.md) | Add scene mass through concrete action/reaction and setting friction, not filler or ornamental language. |
| **12** | [Narrative Revision](./08-narrative-revision-agent.md) | Tighten chapter logic and payoffs with concrete cause/effect links; no abstract thesis patching. |
| — | [Final polish — six-stage pipeline](./final-polish-six-stage-pipeline.md) | **[Critical rules](./final-polish-six-stage-pipeline.md#critical-rules-apply-to-all-stages)** include **concrete-over-poetic** restraint. |

## Suggested workflow (per chapter)

| Step | Agent | When |
|------|--------|------|
| **0** | [Brief-to-Rough-Draft](./00-brief-to-rough-draft.md) | **First:** expand index + synopsis brief into **first full rough draft** (empty or stub chapter) |
| **11** | [Chapter Expansion & Depth](./01-chapter-expansion-depth-pass.md) | **Optional:** if chapter is complete but thin vs Act I; expand character/plot/scenery depth before line-level polish |
| **1** | [Cinematic Scene Pass](./02-cinematic-scene-pass.md) | **Optional:** after **00**—**establishing shots**, light, geography, vivid locatable scenes **before** Flow |
| **2** | [Flow & Clarity Editor](./03-flow-clarity-editor.md) | **Default first revision pass** on prose that already exists *(or first pass after **01**)* — includes optional-but-default-on-full-chapter **paragraph merge** (*single-sentence → multi-sentence blocks*, speaker-safe dialogue) |
| **3** | [Embodiment & Sensory Grounding](./04-embodiment-sensory-grounding.md) | After Flow; **especially** emotional beats |
| **4** | [Dialogue & Voice](./05-dialogue-voice.md) | After Embodiment when dialogue is central |
| **5** | [Thematic Signal](./06-thematic-signal.md) | After dialogue feels stable |
| **6** | [Pacing & Structural Tension](./07-pacing-structural-tension.md) | After thematic pass; hinge moments, drag |
| **12** | [Narrative Revision](./08-narrative-revision-agent.md) | **Optional:** chapter-level coherence pass after **04/05/06** when causality, transitions, or payoffs feel loose |
| **7** | [Audio Read-Aloud](./09-audio-readaloud.md) | **Listener-first** pass (TTS, homophones, obvious stumbles) before calling a chapter done |

### Optional (high-value, specialized)

| Agent | Use when |
|--------|----------|
| [Character Consistency](./10-character-consistency.md) | Chapters drift on Riven/Cael interior logic |
| [Line-Level Precision](./11-line-level-precision.md) | **Sparingly**—repetition, micro-tighten without wrecking rhythm |
| [Narrative Revision](./08-narrative-revision-agent.md) | Chapter works in parts but not yet as one pressure-true arc; run before final audio/cadence polish |
| [Read-Aloud Cadence & Clarity](./12-read-aloud-cadence-clarity-editor.md) | **Optional final polish** after **07**—audiobook-style cadence, connective smoothness, sustained speakability, **subject–verb streaks** / bridge clauses (not a rewrite) |
| [Final polish — six-stage pipeline](./final-polish-six-stage-pipeline.md) | **One prompt, six ordered passes** (flow → embodiment → dialogue → theme → pacing → read-aloud cadence); same layers as **02–06 + 10**, with global critical rules + **POV** + change budget (~5% / ~20% cap) |

If you **already** wrote the chapter by hand, skip **00** and start at **02** *(or run optional **11** first for under-length chapters, then optional **01** if the draft needs a **camera / vivid scene** pass, then **02**, and optional **12** after **04/05/06** if chapter-level coherence still needs unification)*.
