# Velorum Agents

Agent specs are organized into two purpose-based folders:

- **Initial Drafting Pipeline**: `initial-drafting/`
- **Revision Categories**: `revision/`

## How to use

- Use `initial-drafting/` for the core chapter pipeline (rough draft through primary revision/polish chain).
- Use `revision/` for later targeted passes (embodiment, bond tension, myth formation, operational intimacy, dialogue subtext, softness/longing, world pressure, and scene compression).

## Canonical Chain (single source of truth)

Run this default chain unless a chapter has a specific deficit:

1. `initial-drafting/03-flow-clarity-editor.md`
2. `initial-drafting/13-direct-camera-style-pass.md` *(default: American conversational + camera-observable; cut condensed metaphors)*
3. `initial-drafting/04-embodiment-sensory-grounding.md`
4. `initial-drafting/05-dialogue-voice.md`
5. `initial-drafting/06-thematic-signal.md`
6. `initial-drafting/07-pacing-structural-tension.md`
7. `initial-drafting/09-audio-readaloud.md`

Optional branches:

- `initial-drafting/08-narrative-revision-agent.md` when chapter-level causality/payoff coherence is weak
- `initial-drafting/12-read-aloud-cadence-clarity-editor.md` when cadence still fails after `09`
- `revision/` category agents only for targeted deficits
- `revision/05-scene-compression-agent.md` always last

## Concern Ownership

- **Readability/clarity owner:** `03-flow-clarity-editor.md`
- **Direct camera / conversational style owner:** `13-direct-camera-style-pass.md` *(see **voice-spec → Direct camera style pass**)*
- **Audio/cadence gate owner:** `09-audio-readaloud.md` (deep polish: `12-read-aloud-cadence-clarity-editor.md`)
- **Accessibility rescue (non-default):** `revision/10-contemporary-fantasy-accessibility-agent.md`
- **Late decompression/flow rescue (non-default):** `revision/09-contemporary-flow-agent.md`
