## Working practice

1. Open a source log before treating a claim as draft-ready.
2. Tag every entry with one of the four evidence layers.
3. Raise Chapters 4 and 7 dossiers before any narrative drafting.
4. Run the fact-check checklist before marking a drafted unit citation-pass complete.
