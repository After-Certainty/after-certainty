# Upcoming manuscripts

Placeholder folders for books that are **not** yet wired into the publishing pipeline (`books/**/book.yml`). Promote a manuscript into [`books/`](../books/) when it is ready for exports and CI.

## Nonfiction docs convention

Each upcoming **nonfiction** book should maintain:

| File | Purpose |
|------|---------|
| `docs/book-rules.md` | Scope, core invariant, tone, chapter construction |
| `docs/drafting-process.md` | Phased workflow (structure → draft → editorial → promote) |
| `docs/status.md` | Unit-level progress table and next actions |

**Portfolio dashboard:** [`docs/portfolio-status.md`](docs/portfolio-status.md) — all active upcoming nonfiction books at a glance.

**Series guide:** [`docs/series-guide.md`](../docs/series-guide.md) — reading order, clusters, and easily confused title pairs.

**Templates:** [`docs/_templates/`](docs/_templates/) — copy when scaffolding a new upcoming title.

Refresh the portfolio row whenever a book's `docs/status.md` changes phase or next actions materially.

## Fiction exception

Fiction manuscripts use a separate track (planning under `docs/`, not the nonfiction `book-rules` / `drafting-process` trio). They are not listed on the nonfiction portfolio dashboard.

**Promoted to `books/`:** **What We Cannot See** — [`books/what-we-cannot-see/`](../books/what-we-cannot-see/) (epistemic limits; exports enabled). **Velorum** — [`books/velorum/`](../books/velorum/) (mythic fantasy; exports enabled). **Boundary Conditions** — [`books/boundary-conditions/`](../books/boundary-conditions/) (organizational fiction novel; exports enabled). **The Economy We Don't Experience** — [`books/the-economy-we-dont-experience/`](../books/the-economy-we-dont-experience/) (~28–32k edition; exports enabled). **When Incentives Become the Moral Language** — [`books/when-incentives-become-the-moral-language/`](../books/when-incentives-become-the-moral-language/) (essay edition; exports enabled). **Why Collaboration Is So Hard** — [`books/why-collaboration-is-so-hard/`](../books/why-collaboration-is-so-hard/) (essay edition; exports enabled). **How Trust Forms** — [`books/how-trust-forms/`](../books/how-trust-forms/) (trust trilogy formation; exports enabled). **When Trust Stops Tracking Reality** — [`books/when-trust-stops-tracking-reality/`](../books/when-trust-stops-tracking-reality/) (trust trilogy tension; exports enabled). **Trust Beyond Similarity** — [`books/trust-beyond-similarity/`](../books/trust-beyond-similarity/) (trust trilogy practice; exports enabled). **Observer Patterns** — [`books/observer-patterns/`](../books/observer-patterns/) (poetry; Typst PDF only).

Do not recreate Pass 4 promote stub folders under `upcoming/` (e.g. `upcoming/after-certainty/` with only export artifacts). Published copies live under `books/` only.
