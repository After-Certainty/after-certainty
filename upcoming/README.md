# Upcoming manuscripts

Placeholder folders for books that are **not** yet wired into the publishing pipeline (`books/**/book.yml`). Promote a manuscript into [`books/`](../books/) when it is ready for exports and CI.

## Nonfiction docs convention

Each upcoming **nonfiction** book should maintain:

| File | Purpose |
|------|---------|
| `docs/book-rules.md` | Scope, core invariant, tone, chapter construction |
| `docs/drafting-process.md` | Phased workflow (structure → draft → editorial → promote) |
| `docs/status.md` | Unit-level progress table and next actions |

**Portfolio dashboard:** [`docs/portfolio-status.md`](docs/portfolio-status.md) — all active upcoming nonfiction books at a glance.

**Series guide:** [`docs/series-guide.md`](../docs/series-guide.md) — reading order, clusters, and easily confused title pairs.

**Templates:** [`docs/_templates/`](docs/_templates/) — copy when scaffolding a new upcoming title.

Refresh the portfolio row whenever a book's `docs/status.md` changes phase or next actions materially.

## Fiction exception

Fiction manuscripts use a separate track (planning under `docs/`, not the nonfiction `book-rules` / `drafting-process` trio). They are not listed on the nonfiction portfolio dashboard.

| Slug | Notes |
|------|-------|
| [`velorum/`](velorum/) | Mythic fantasy — `project-spec.md`, `voice-spec.md`, agent pipeline under `velorum/docs/` |

**Promoted to `books/`:** **Boundary Conditions** — [`books/boundary-conditions/`](../books/boundary-conditions/) (organizational fiction novel; exports enabled).
