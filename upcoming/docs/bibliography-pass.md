# Bibliography and citation pass (upcoming nonfiction)

Use the same workflow as published books. Full pass instructions:

[books/how-meaning-moves/docs/bibliography-pass.md](../books/how-meaning-moves/docs/bibliography-pass.md)

**Upcoming conventions:**

- Pandoc footnotes with chapter-scoped IDs (`[^c3-douglas-purity-danger]`)
- `back-matter/bibliography.md` with Chicago-style dash bullets (see `books/when-others-look-to-you/v2/back-matter/bibliography.md`)
- No `back-matter/endnotes.md` on upcoming titles
- **Blank line before each `[^id]:` definition block** (required for Pandoc/EPUB; definitions on the line immediately after prose render as literal `[^id]` in Apple Books)
