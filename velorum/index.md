# Velorum

## Manuscript hub

This folder is a **book root** for the shared export pipeline: `make export-docx DIR=velorum` and `make export-kindle-epub DIR=velorum` (from the repo root) produce `velorum/velorum.docx` and `velorum/velorum.epub` by concatenating the linked chapter files **in the order below**.

- **Plot / POV spine:** [`docs/act-chapter-index.md`](docs/act-chapter-index.md)  
- **Drafting & agents:** [`docs/agents/README.md`](docs/agents/README.md)
