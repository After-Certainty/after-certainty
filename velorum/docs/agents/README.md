# Velorum — agent specs

**One drafting agent** plus **nine revision agents**. Copy a spec into a Cursor agent prompt (with the chapter file and linked docs) or use as a human checklist.

**Not every revision pass every time**—run agents **01–08** when the draft needs that layer; **[09](./09-read-aloud-cadence-clarity-editor.md)** is an **optional final polish** after **06** when audiobook-style cadence is the bar. For **one chained prompt** that runs **01 → 05** then **09** as ordered stages (shared rules + change budget), see **[final-polish-six-stage-pipeline](./final-polish-six-stage-pipeline.md)**.

**House rules (agents do not override):**  
[project-spec.md](../project-spec.md) → [voice-spec.md](../voice-spec.md) → [synopsis.md](../synopsis.md) / [act-chapter-index.md](../act-chapter-index.md)

**Detailed checklists:** [chapter-edit-pass.md](../chapter-edit-pass.md)  
**Gold-chapter habits:** [exemplar-chapter-01-drafting.md](../exemplar-chapter-01-drafting.md)  
**Bookish register (sayable mouth):** catch early in **[01-flow-clarity-editor.md](./01-flow-clarity-editor.md)** (narration + whole chapter), dialogue-heavy beats in **[03-dialogue-voice.md](./03-dialogue-voice.md)**, listener triage in **[06-audio-readaloud.md](./06-audio-readaloud.md)**, optional sustained cadence polish in **[09-read-aloud-cadence-clarity-editor.md](./09-read-aloud-cadence-clarity-editor.md)**; rough-draft default in **[00-brief-to-rough-draft.md](./00-brief-to-rough-draft.md)**.

## Suggested workflow (per chapter)

| Step | Agent | When |
|------|--------|------|
| **0** | [Brief-to-Rough-Draft](./00-brief-to-rough-draft.md) | **First:** expand index + synopsis brief into **first full rough draft** (empty or stub chapter) |
| 1 | [Flow & Clarity Editor](./01-flow-clarity-editor.md) | **Default first revision pass** on prose that already exists |
| 2 | [Embodiment & Sensory Grounding](./02-embodiment-sensory-grounding.md) | After Flow; **especially** emotional beats |
| 3 | [Dialogue & Voice](./03-dialogue-voice.md) | After Embodiment when dialogue is central |
| 4 | [Thematic Signal](./04-thematic-signal.md) | After dialogue feels stable |
| 5 | [Pacing & Structural Tension](./05-pacing-structural-tension.md) | After thematic pass; hinge moments, drag |
| 6 | [Audio Read-Aloud](./06-audio-readaloud.md) | **Listener-first** pass (TTS, homophones, obvious stumbles) before calling a chapter done |

### Optional (high-value, specialized)

| Agent | Use when |
|--------|----------|
| [Character Consistency](./07-character-consistency.md) | Chapters drift on Riven/Cael interior logic |
| [Line-Level Precision](./08-line-level-precision.md) | **Sparingly**—repetition, micro-tighten without wrecking rhythm |
| [Read-Aloud Cadence & Clarity](./09-read-aloud-cadence-clarity-editor.md) | **Optional final polish** after **06**—audiobook-style cadence, connective smoothness, sustained speakability (not a rewrite) |
| [Final polish — six-stage pipeline](./final-polish-six-stage-pipeline.md) | **One prompt, six ordered passes** (flow → embodiment → dialogue → theme → pacing → read-aloud); same layers as **01–05 + 09**, with global critical rules and change budget (~5% / ~20% cap) |

If you **already** wrote the chapter by hand, skip **00** and start at **01**.
