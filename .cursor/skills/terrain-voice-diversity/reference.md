# Terrain & voice diversity — reference

## Agent spec

`books/after-certainty/docs/agents/05-terrain-voice-diversity.md`

## Core principle

> Preserve the insight. Vary the terrain.

## Domain palette

Use 1–2 per unit; track across manuscript to avoid repetition.

| Domain | Examples |
|--------|----------|
| Nature | rivers, erosion, weather, forests, migration, drought, seasons, coastlines |
| Family | parenting, siblings, marriage, caregiving, aging parents, inherited stories |
| Friendship | estrangement, loyalty, repair, misunderstanding, shared history |
| Education | classrooms, teachers, learning, study, expertise |
| Medicine | diagnosis, treatment, triage, recovery, uncertainty |
| Art & literature | storytelling, editing, performance, interpretation |
| Ordinary life | neighborhoods, travel, waiting rooms, dinner tables, community events |

**Keep** organizational examples (meetings, reports, dashboards, files, statements).

## Inquiry pivot alternatives

| Over-used | Alternatives |
|-----------|--------------|
| Perhaps. | Maybe. / Not entirely. / The explanation is not wrong. / Something else may be happening. / And yet... / That account leaves something out. |
| At first the answer seems obvious... | The natural conclusion is... / One explanation is... / Most people would assume... / It is tempting to conclude... / The surface explanation is... |

Vary 2–4 per unit where repetitive—not every instance.

## Imagery variants

| Recurring | Vary to |
|-----------|---------|
| dashboard | trend line, scorecard, summary table, attendance chart |
| metric | quarterly report, poll, ranking, forecast |
| report | briefing, summary, case file, chart |
| file | folder, record, docket, open question |

## Observation over declaration

| Weak | Strong |
|------|--------|
| People seek certainty. | The room had stopped asking whether the answer was correct and started asking whether anyone could tolerate another week without one. |
| Abstraction hides people. | The report improved while the same family was still waiting for the call. |
