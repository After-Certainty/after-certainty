# Timeline & sequencing pass — The Relay

Read and follow **[17-timeline-sequencing-agent.md](../../books/the-relay/docs/agents/17-timeline-sequencing-agent.md)** in full.

## Workflow

1. **Load** chapter file + [iconic-locations.md](../../books/the-relay/docs/iconic-locations.md) + [act-chapter-index.md](../../books/the-relay/docs/act-chapter-index.md).
2. **Build timeline spine** before editing: `TIME — PLACE — EVENT — READER LEARNS`.
3. **Audit opening** (~first 300 words): undefined nouns, page-one checklist, habitat line after visual anchor.
4. **Flag** chronology bugs (effect before cause), spatial jumps (no hinge at `---`), duplicate beats.
5. **Fix in manuscript** — reorder, hinge, trim duplicate orientation; do not add plot.
6. **Deliver** orientation score, spine, flags table, and what changed.

## When to run

- First polish on every chapter (with or after flow-clarity).
- Mandatory after structural reorder, flashback insert, or opening rewrite.
- Act I Ch. 1–5: run on full act if any chapter was resequenced.

## Do not

- Add glossary paragraphs or Velorum-style mechanism lectures.
- Cut protected set-pieces (hangar, pilgrim, COMMITTED, Lake Orin opening).
- Flatten voice in hinge sentences.
