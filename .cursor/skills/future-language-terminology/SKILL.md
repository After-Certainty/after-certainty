# Future language & terminology pass — The Relay

Read and follow **[19-future-language-terminology-agent.md](../../books/the-relay/docs/agents/19-future-language-terminology-agent.md)** and **[future-language-audit.md](../../books/the-relay/docs/future-language-audit.md)**.

## Workflow

1. **Load** chapter + audit doc.
2. **Flag** every invented/unusual term; run four questions per term.
3. **Replace** friction terms with operational alternatives—context-aware, not blind global replace.
4. **Preserve** earned coinage (story tax, thread wall, keeper, relay, Consensus Bureau).
5. **Preserve** anatomical *throat* and human-body idioms.
6. **Deliver** per-term table: original → why → replacement → sample sentence.

**Pipeline:** After future texture (18), before contemporary readability (16).
