# Author intrusion pass — The Relay

Read and follow **[22-author-intrusion-agent.md](../../books/the-relay/docs/agents/22-author-intrusion-agent.md)** and **[author-intrusion-patterns.md](../../books/the-relay/docs/author-intrusion-patterns.md)**.

## Workflow

1. **Load** chapter + [motifs.md](../../books/the-relay/docs/motifs.md) + [project-spec.md](../../books/the-relay/docs/project-spec.md).
2. **Scan** narration for categories 1–5 (structure, explain-after-show, relationship summary, dev-editor voice, theme restatement).
3. **Flag** each intrusion with severity and disposition (CUT / REDUCE / CONVERT TO SCENE / CONVERT TO DIALOGUE / KEEP).
4. **Do not rewrite** unless user explicitly approves follow-up pass.
5. **List** top 3 intrusions, protected beats, theme stack count.
6. **Append** new flags to author-intrusion-patterns.md.

**Pipeline:** After contemporary dialogue (21), before Brittany (14).

**Priority:** Act V (Ch. 23–27), then Ch. 22, 25, 18.
