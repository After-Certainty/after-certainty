# Curiosity expansion — reference

## Agent spec

`books/after-certainty/docs/agents/02-curiosity-expansion.md`

## Core instruction

> Find every place where the manuscript poses a genuinely interesting question and answers it within the next 1–3 paragraphs. Expand the space between question and answer. Explore before concluding.

## Ch 1 exemplar

**Question:** Why had winning felt so dangerous?

**Bad (answers too fast):**

> Perhaps because being right promises more than accuracy.
>
> It promises stability.

**Good (investigate first):**

> At first the answer seemed obvious… But that explanation felt too small.
>
> …facts carrying burdens facts were never meant to carry…
>
> …Identity. The right answer starts carrying the weight of the self.
>
> Correctness feels like safety.

## Good vs bad

| Bad | Good |
|-----|------|
| Add another question before the pattern | Expand investigation after existing question |
| Multi-domain example lists | Follow one question's implications |
| Decorative literary wandering | Intellectual wandering; writer investigates |
| Answer within 1–3 paragraphs | Wander, then arrive |

## Success checklist

- [ ] Interesting questions investigated before answers
- [ ] Writer appears curious, not lecturing
- [ ] Pattern earned through investigation
- [ ] Bold compression at chapter end intact
- [ ] Chain to recognition-preservation on same unit
