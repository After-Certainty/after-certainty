# First-read snag pass — The Relay

Read and follow **[20-first-read-snag-agent.md](../../books/the-relay/docs/agents/20-first-read-snag-agent.md)** and **[first-read-snag-patterns.md](../../books/the-relay/docs/first-read-snag-patterns.md)**.

## Workflow

1. **Read** chapter line by line as a first-time reader.
2. **Flag** any sentence requiring re-read or mental translation.
3. **Classify** snag (compressed grammar, weather shorthand, thesis narration, wordplay, label→behavior, personified infra, ops jargon).
4. **Fix** with smallest change; apply to manuscript.
5. **Preserve** earned coinage, Jun/Dael register, anatomical *throat*.
6. **Deliver** snag table + borderline list.

**Pipeline:** After terminology (19), before Brittany (14).

**Do not:** add clue systems, cut set-pieces, or run terminology coinage audit (that's agent 19).
