# Contemporary dialogue pass — The Relay

Read and follow **[21-contemporary-dialogue-agent.md](../../books/the-relay/docs/agents/21-contemporary-dialogue-agent.md)** and **[contemporary-dialogue-patterns.md](../../books/the-relay/docs/contemporary-dialogue-patterns.md)**.

## Workflow

1. **Load** chapter + [voice-spec.md](../../books/the-relay/docs/voice-spec.md) + [character-bible.md](../../books/the-relay/docs/character-bible.md).
2. **Scan** all quoted dialogue for red flags (aphorisms, thesis, essay either/or).
3. **Rewrite** exchanges into multi-beat arguments; preserve goals and subtext.
4. **Protect** profanity, Jun chart register (brief), good lines in patterns doc.
5. **Update** contemporary-dialogue-patterns.md with new flags/fixes.
6. **Deliver** flag table + note 2–3 protected lines.

**Pipeline:** After first-read snag (20), before Brittany (14). Complements dialogue agent (01).

**Do not:** flatten character intelligence; move theme into narration wholesale; cut set-pieces.
