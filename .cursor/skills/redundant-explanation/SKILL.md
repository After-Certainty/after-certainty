# Redundant explanation pass — The Relay

Read and follow **[23-redundant-explanation-agent.md](../../books/the-relay/docs/agents/23-redundant-explanation-agent.md)** and **[redundant-explanation-patterns.md](../../books/the-relay/docs/redundant-explanation-patterns.md)**.

## Workflow

1. **Read** chapter scene-by-scene (blocks between `---`).
2. **Apply delete test** to the 1–3 paragraphs after each block and to chapter closings.
3. **Flag** retell paragraphs with recommendation: DELETE | MERGE ONE DETAIL | KEEP.
4. **Do not delete** without approval; do not remove sole momentum beats.
5. **Summarize** delete candidates and word recovery estimate.
6. **Update** redundant-explanation-patterns.md.

**Core question:** If this paragraph were deleted, would the reader still understand the point? If yes → recommend deletion.

**Pipeline:** After author intrusion (22), before Brittany (14).
