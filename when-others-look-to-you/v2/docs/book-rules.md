# Writing style and book rules — v2 scope

## Where the full directive lives

The complete **tone, callout, pattern block, vignette, footnote, and
meta-language** rules for *When Others Look to You* are in:

**`../v1/docs/book-rules.md`**

That file is long and includes **v1 chapter-numbered examples** (e.g. circulation
weave, Part III echo guardrails). Treat those examples as **illustrations of the
rule**, not as claims about v2’s chapter titles.

---

## What v2 adds or changes (structural)

1. **Four manuscript parts** — Forming, Renewing, Eroding, Repeating — not v1’s
   three thematic parts. Bridges should frame transitions between those
   movements.

2. **One pattern per chapter (chapters 1–10)** — The named dynamics in Appendix B
   appear as **chapter subjects** in order. You are not “inserting” pattern
   blocks into unrelated chapter titles; the chapter **is** the pattern. Still
   follow **`book-rules.md`** on how **Pattern Blocks** and pull quotes are
   styled when you use them.

3. **Part labels vs appendix labels** — Manuscript parts use **Renewing** and
   **Repeating**; Appendix B groups use **Adjusting** and **Circulating**. That
   is intentional; do not force the manuscript part titles to match the appendix
   section labels unless you choose to align them in a future edit.

4. **Circulation** — v1’s standalone `circulation-cross-cutting.md` restructure
   does **not** apply to v2. Circulation dynamics are still described by the same
   patterns (especially **Leadership Reproduces Itself**, **Dissent is
   Welcomed**, **Learning Collapses**).

5. **Renewal / erosion vocabulary** — v1 centers an explicit renewal/erosion
   model in early chapters. v2’s **Eroding** part covers erosion-shaped patterns
   without necessarily importing v1’s full “vitality / decay” scaffolding unless
   you add it. If you do, keep v1’s **direction vs state** and **word valence**
   rules from the full `book-rules.md`.
