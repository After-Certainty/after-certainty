# Pattern integration — v2 manuscript

## Relationship to v1’s guide

The full **Pattern Integration Guide** is **`../v1/docs/pattern-integration-guide.md`**. It was written for a manuscript where patterns were **additive**—named dynamics placed inside chapters whose primary titles were thematic (harm, scale, etc.).

The **v2** manuscript uses a **pattern spine**: one Appendix B pattern per chapter, in order, grouped under four movements (Forming, Renewing, Eroding, Repeating). Many of v1’s **placement tables** and **circulation-merge** notes do not apply line-for-line.

---

## What still applies from v1

- **Core principles:** Patterns are observational, not prescriptive; preserve calm, structural voice; avoid management-speak and slogans.
- **Named dynamics** — Bold titles, consistent with Appendix B; see `book-rules.md` in v1 for **Pattern Block** mechanics and **positive-only** renewing bodies where those rules still make sense for the renewing chapters.
- **Cross-references** — “Related patterns” style links between chapters can still be used where they help the reader; v2’s order makes forward/back references natural.

---

## What is different in v2

- **No separate “integration pass” to map patterns onto chapters** — the chapter title is the pattern. Use bridges to explain **why** the next movement matters, not to reintroduce pattern names cold.
- **Leadership Reproduces Itself** is the capstone in Part IV; v1’s placement notes after the circulation merge are **history only** for v2.
- If you add **optional** pattern callouts beyond the chapter heading, treat them as **reinforcement**, not redundancy with the chapter’s main argument.

---

## When to open v1’s full guide

Use v1 **`pattern-integration-guide.md`** when you need **word-level** rules for Pattern Block formatting, pull-quote placement, or footnote adjacency—especially if v2 starts using the same `::: … :::` conventions as v1 exports.
