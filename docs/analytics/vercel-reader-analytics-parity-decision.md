## Gate 3 questions

### 1. What Vercel measures reliably

- Always-on visits: pageviews, visitors, path, country, device, referrer, environment.
- Custom reader vocabulary (owner smoke): `chapter_open`, `chapter_advance`, `book_download`, `corpus_navigation` with bounded properties.
- Joint attribution: `requestPath` × `to_id` and `from_type` × `to_type` (≤2 `by=` dimensions).
- Reporting stack (PR 2) + `vercel.analytics.read` PADE capability.

### 2. What differs from GA4

| Topic | Difference |
|-------|------------|
| Consent | Vercel ungated; GA4 gated |
| Volume | Vercel ≫ GA4 (expected) |
| Event names | `chapter_advance` / `book_download` vs GA `next_chapter` / `file_download` |
| Journeys | Aggregate only on Vercel |
| Search / catalog | Still richer on GA4 |
| Time bounds | Vercel UTC midnights vs GA4 Denver midnights for the same date labels |

### 3. What would be lost by retiring GA4 now

Consent-scoped engagement, `ga-trends` continuity, search/secondary taxonomy, and confidence from a full 2–4 week dual-write window.

### 4. Whether remaining gaps matter

| Gap | Matters now? |
|-----|--------------|
| Observation window incomplete | **Yes — blocks PR 4** |
| Owner smoke both sinks | Useful; not per-click proof |
| Sparse organic dual-write | Yes for decision quality |
| Session journeys | Accepted |
| Cost monitoring | Ongoing |

### 5. Cost outcomes

| Item | Figure |
|------|--------|
| Plan | Pro |
| Web Analytics Plus | **~$10/mo** (invoice `analytics` price field 1000 → cents) |
| Published custom event price | **$0.00003 / event** ($3 / 100k) — [Vercel pricing](https://vercel.com/docs/analytics/limits-and-pricing) |
| Invoice `webAnalyticsEvent.price` 0.003 | Interpreted as **0.003 cents** (= $0.00003), **not** $0.003 USD/event |

No unexpected cost spike observed yet; re-check Usage at revisit.

### 6. Explicit recommendation

- Corrective PR: none required from owner smoke for core event presence.
- **PR 4 blocked** until human approval after the observation window.
