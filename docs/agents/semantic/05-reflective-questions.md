# Reflective questions

**Agent type:** `questions`  
**Canonical field:** `questions`

## Task

Write **inquiry prompts** that help a reader locate the pattern in their own context.

## Output

```yaml
items:
  - open question (not yes/no)
```

## Quality bar

- Questions invite reflection, not quizzes with one right answer.
- 2–4 questions per entity; avoid jargon without glossary linkage.

## Do not

- Use questions as disguised assertions or slogans.
